# Портфолио Владимира Тарасенко

Статический персональный сайт в концепции «Личный журнал»: профессиональная история, восемь кейсов, подход к работе и контакты. Страница оформлена крупной типографикой на молочном фоне с терракотовыми акцентами.

## Устройство сайта

Сайт разделён на три слоя: HTML хранит содержание, CSS определяет оформление, JavaScript добавляет интерактивность. Все необходимые ресурсы находятся в этой папке. Сборка, база данных и серверное приложение не требуются.

`index.html` содержит готовую страницу: первый экран, главы карьеры, карточки и подробности проектов, описание подхода и контакты. Контент не запрашивается по API и не генерируется скриптами. Без JavaScript история, подробности и контакты остаются доступными.

## Стили

| Файл | Ответственность |
| --- | --- |
| `styles/base.css` | Базовые переменные, сброс стилей, типографика и клавиатурный фокус |
| `styles/layout.css` | Контейнер, липкая шапка, сетки и отступы якорей |
| `styles/components.css` | Главы, кнопки, результаты, карточки и диалог |
| `styles/motion.css` | Появления элементов и reduced motion |
| `styles/journal.css` | Экранная тема «Личный журнал» и адаптивная композиция |
| `styles/print.css` | Печатная версия с раскрытыми описаниями |

Тема журнала применяется только к экранному режиму. На широком экране история имеет боковое оглавление, а кейсы занимают две колонки. На телефоне карточки выстраиваются вертикально. Размеры текста и отступы адаптируются через CSS Grid, Flexbox и `clamp()`.

Playfair Display и Inter загружаются из `assets/fonts/`. Локальные WOFF2 содержат кириллицу и латиницу; `font-display: swap` позволяет читать текст до загрузки шрифтов. Декоративные иллюстрации кейсов созданы HTML и CSS.

## Интерактивность

`scripts/main.js` загружает три браузерных ES-модуля и запускает их инициализацию отдельно.

- `navigation.js` использует `IntersectionObserver` для выбора первой видимой главы ниже шапки. Ссылка в оглавлении получает маркер, выделенное начертание и `aria-current`.
- `case-dialog.js` переносит существующее описание из карточки в нативный `<dialog>`. При закрытии возвращает тот же узел, фокус и позицию прокрутки. Копий контента и повторяющихся идентификаторов не создаётся.
- `motion.js` отмечает первое появление главы классом `.is-inview`. Анимация задана в CSS и отключается при `prefers-reduced-motion`.

Диалог открывается мышью или клавиатурой и закрывается кнопкой, Escape или кликом вне панели. На телефоне он занимает экран. Пока диалог открыт, фоновая страница зафиксирована.

## Доступность и печать

Страница использует семантические разделы, иерархию заголовков, ссылку пропуска и видимый клавиатурный фокус. Декоративные панели скрыты от скринридера, а значимые факты доступны в обычном тексте.

Печатные стили убирают навигацию и декорации и раскрывают описания проектов. Перед печатью открытый диалог закрывается, возвращая содержимое в документ.

## Запуск

Из этой папки при установленном Python 3:

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:8765/`. Для остановки нажмите `Ctrl+C`. HTTP нужен для корректной загрузки ES-модулей; npm-зависимости для просмотра не требуются.

## Проверки и размещение

В корне репозитория настроены 25 тестов Playwright: навигация, диалоги, мобильная вёрстка, клавиатура, печать, увеличенный текст, reduced motion и работа без JavaScript. Тестовый сервер запускается автоматически.

Для размещения статический хостинг должен отдавать содержимое этой папки с сохранением относительных путей. Сборка, переменные окружения и серверный роутер не нужны: навигация использует якоря одной страницы.
